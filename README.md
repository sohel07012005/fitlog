->Project : FitLog

->Description : It is designed to make workout planning simple and organized. Users can explore different workouts, view workout details, add workouts to their today's plan, save workouts for later, mark completed workouts, and sort workouts based on duration or rating.

-> Technologies Used :
- Next.js
- React.js
- TypeScript
- Tailwind CSS
- React Icons
- React Toastify


-> Main Features : 

1. Workout Library:
 Users can browse a collection of different workouts with useful information such as:

- Workout name
- Equipment
- Duration
- Calories burned
- Rating
- Workout image


2. Today's Workout Plan: 
Users can add workouts to their personal Today's Plan and manage their daily workout activities from one place.


3. Saved Workouts: 
Users can save their favorite workouts for later. Saved workouts are available separately in the Saved section.



4. Mark As Done:
 Users can mark a workout as completed from Today's Plan. After marking a workout as done:

- The button changes to Done
- The button becomes disabled
- The completed workout name changes to gray
- Only the selected workout is affected


5. workout Sorting:
Users can organize workouts using different sorting options:

- Duration
- Calories
- Rating
